# Neocities Page
`andraguoso.neocities.org`: Blog with experimental features built in vanilla JavaScript, mostly a never-ending CSS exercise.

## Structure

```text
.
├── ac/                      # Album cover artwork
├── pic/                     # Artist images
├── blog.html                # Self-explanatory
├── index.html               # Homepage
├── nopoint.html             # HTML experiments
├── nospaces.html            # JavaScript, Flexbox experiments
├── script.js                # Expand/collapse interactions
└── styles.css               # Shared stylesheet
```
